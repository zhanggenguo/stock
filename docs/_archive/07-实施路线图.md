# 07 — 实施路线图

## 1. 分期建设

### Phase 0 — 设计与验证（1 周，当前阶段）

**目标**：验证接口可用性与数据质量，不写业务代码。

- [x] 完成系统设计文档（本套）
- [ ] 对 02 文档中的每个接口做连通性实测，记录可用字段、返回样例、限流表现
- [ ] 选 5 家样本公司（覆盖沪/深/科创/北交所），手工跑通：基本信息 → 主营构成 → 三大报表 → 公告 PDF
- [ ] 验证 `secid` / F10 `code` / 巨潮 orgId 映射正确性
- [ ] 输出《接口实测报告》，修订 02 文档

**验收**：每个接口有 1 份真实返回样例存档于 `data/raw/samples/`；映射零错误。

### Phase 1 — 企业信息库与主数据（2~3 周）

**目标**：建成"完整股市企业基本信息库"（需求①）。

- [ ] 建库：`dim_company`, `dim_company_identifier`, `fact_company_profile`, `dim_industry`, `company_industry_map`
- [ ] 连接器：证券列表、F10 CompanySurvey、行业板块
- [ ] 调度：周更新 + 增量
- [ ] 最小 Web：公司搜索、档案页、行业归属

**验收**：全 A 股覆盖 ≥ 99%，代码映射 100% 正确，每周自动更新。

### Phase 2 — 财务 / 业务构成 / 龙头识别（3~4 周）

**目标**：需求②③。

- [ ] 连接器：datacenter 三大报表与指标、F10 主营构成、公告检索
- [ ] 建表：`fact_financial`, `fact_business_segment`, `fact_quote_snapshot`
- [ ] 算法：业务构成解析与校验、龙头评分与分层（04 文档第 1、2 节）
- [ ] Web：行业龙头榜、个股业务构成图、变更日志
- [ ] 回测：核心龙头名单 1 年表现 vs 行业中位数

**验收**：核心龙头每赛道 ≤ 3 家且变化可解释；业务构成占比校验通过率 ≥ 98%。

### Phase 3 — 政策层（2~3 周）

**目标**：需求④⑤。

- [ ] 政策白名单源接入（国务院、发改委、工信部、财政部、证监会）
- [ ] 增量识别规则引擎 + 行业映射 + 人工复核工作台
- [ ] 扶持度/重要度打分、时效衰减、影响传导
- [ ] Web：政策时间轴、行业政策权重、企业影响预警

**验收**：政策文件只来自官方源；每条影响有原文证据；无误把新闻当政策（人工抽检 20 条）。

### Phase 4 — 价值评估与观点（3~4 周）

**目标**：需求⑥。

- [ ] 公司类型判定 + 多方法估值 + 历史分位
- [ ] 安全边际计算、观点合成、反证信号
- [ ] 证据链服务、人工复核发布流程
- [ ] Web：估值区间 vs 市场价、观点卡片、免责声明
- [ ] 历史切片回测，检查评级区分度

**验收**：每个已发布观点可点击追溯到来源；无目标价/买卖指令字样；回测区分度报告留存。

### Phase 5 — 稳健化与合规（持续）

- [ ] 全链路监控告警、保鲜期提示
- [ ] 数据质量报告每周邮件/站内推送
- [ ] 若商业化：评估授权数据源替换方案
- [ ] 权限控制、操作审计

## 2. MVP 建议范围（最小可用）

只做"**一个行业 + 30 家公司**"的闭环：

```
公司档案 → 财务 → 主营构成 → 龙头评分 → 政策权重 → 估值观点 → 证据链 → 工作台
```

目的：用最小成本验证六个环节能否串通、算法输出是否合理，再扩展到全市场。

## 3. 关键里程碑与交付物

| 里程碑 | 交付物 | 决策点 |
|---|---|---|
| M0 | 接口实测报告 | 免费源够不够用？是否需要付费源 |
| M1 | 企业信息库 + 档案页 | 数据覆盖率是否达标 |
| M2 | 龙头榜 + 业务构成 | 龙头名单是否符合行业常识 |
| M3 | 政策看板 + 影响预警 | 增量识别准确率是否可接受 |
| M4 | 估值观点 + 回测报告 | 评级是否有区分度 |
| M5 | 监控合规体系 | 是否具备对外使用条件 |

## 4. 当前未决事项（需用户确认）

1. **市场范围**：先做 A 股，还是同时纳入港股/美股？（本设计按 A 股起步）
2. **细分赛道口径**：用东财行业、申万行业，还是自建 CUSTOM 赛道？龙头识别的粒度取决于此。
3. **政策源白名单**：除了国务院/发改委/工信部/财政部/证监会，是否加入特定省份或行业主管部门？
4. **是否引入 LLM**：仅做政策文本辅助分类，还是完全用规则？引入则增加证据审计成本。
5. **使用性质**：个人研究工具还是商业化产品？后者必须换授权数据源。
6. **部署形态**：本地单机还是服务器常驻？影响调度与采集限速策略。
7. **回测历史深度**：估值分位取 5 年还是 10 年（数据可得性决定）。

> 以上问题不阻塞 Phase 0 的接口实测；可在实测后一并决策。
