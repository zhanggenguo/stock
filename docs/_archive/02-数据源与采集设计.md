# 02 — 数据源与采集设计

> 接口形态来自公开资料调研（截至 2026-11），**均为网页/移动端背后的非官方公开接口，可能随时改版**。实施前必须对每条接口做连通性实测，并在连接器里做"字段缺失即降级"处理。不依赖任何单一接口作为唯一来源。

## 1. 数据源清单与分级

| 级别 | 数据源 | 覆盖内容 | 用途定位 | 风险 |
|---|---|---|---|---|
| A（一手/权威） | 巨潮资讯网 cninfo | 法定公告、定期报告 PDF、公告分类检索 | 业务构成原文、公告原文、事实核对 | 需 PDF 解析；有反爬 |
| A | 上交所/深交所/北交所官网 | 公告、规则、监管文件 | 政策与公告权威核对 | 结构不统一 |
| B（结构化主力） | 东方财富 F10 / push2 / datacenter | 基本信息、主营构成、三大报表、指标、行情、行业板块 | 批量结构化主力源 | 非官方 API，按 IP 限流 |
| B | 东方财富公告 np-anotice | 公告列表兜底 | 巨潮失败时兜底 | 权威性低于巨潮 |
| C（补充） | 政府网站（国务院/发改委/工信部/财政部/证监会等） | 政策原文 | 政策层采集 | 无统一 API，需定向解析 |
| C | AkShare / Tushare | 上述源的封装或补充 | 快速验证、字段补齐 | 上游改版即失效；Tushare 有积分门槛 |
| D（付费备选） | Choice / iFinD / Wind | 全量清洗数据 | 商业化的合规替代 | 年费，需预算决策 |

**策略**：A 类做"核对/原文层"，B 类做"批量结构化层"，C 类做"政策/补缺层"。任何 B/C 类结论若进入最终观点，尽量有 A 类原文可回溯；无法回溯的标 `confidence=low`。

## 2. 接口明细（实测前按此接入，接入后校准）

### 2.1 东方财富 — 证券列表与行情（push2）

```http
# 全市场列表/排行
GET https://push2.eastmoney.com/api/qt/clist/get
    ?fs=m:0+t:6,m:0+t:80,m:1+t:2,m:1+t:23,m:0+t:81+s:2048
    &fields=f12,f14,f20,f21,f9,f23,f2,f3
    &pn=1&pz=100&fid=f20&po=1
    &ut=bd1d9ddb04089700cf9c27f6f7426281

# 单只快照
GET https://push2.eastmoney.com/api/qt/stock/get?secid=1.600519&fields=...

# 批量快照（建议每批 ≤ 50 个 secid）
GET https://push2.eastmoney.com/api/qt/ulist.np/get?secids=1.600519,0.000001&fields=...

# 历史K线
GET https://push2his.eastmoney.com/api/qt/stock/kline/get
    ?secid=1.600519&klt=101&fqt=1&fields1=f1,f2,f3&fields2=f51,f52,f53,f54,f55,f56,f57
```

- `secid` 规则：沪市（含科创板）`1.`；深市（含创业板）、北交所 `0.`；港股 `116.`；纳斯达克 `105.`；纽交所 `106.`。
- 常用字段：`f12` 代码、`f14` 名称、`f20` 总市值、`f21` 流通市值、`f9` PE(TTM)、`f23` PB、`f2` 最新价、`f3` 涨跌幅。
- **坑**：市场号写错静默返回另一标的（`0.000001`=平安银行，`1.000001`=上证指数）。映射校验是硬门禁。
- `fqt`：0 不复权 / 1 前复权 / 2 后复权；估值比较统一用不复权价格 + 当期股本口径。

### 2.2 东方财富 — 公司基本信息与主营构成（F10 PageAjax）

```http
# 公司概况
GET https://emweb.securities.eastmoney.com/PC_HSF10/CompanySurvey/PageAjax?code=SZ000001

# 主营构成（按行业/产品/地区）
GET https://emweb.securities.eastmoney.com/PC_HSF10/BusinessAnalysis/PageAjax?code=SZ000001
```

- `code` 参数格式：`SH600519` / `SZ000001` / `BJ430047`（大写前缀 + 6 位代码），**与 push2 的 secid 不同**。
- 主营构成返回 `zygcfx` 数组，字段含：报告期、分类方向（行业/产品/地区）、分类名、主营收入、收入占比、主营成本、成本占比、主营利润、利润占比、毛利率。
- 这是"补齐信息识别龙头"与"业务构成及占比"最直接的数据源；但它是二次加工口径，需与巨潮年报原文抽检核对。

### 2.3 东方财富 — 财务报表（datacenter-web 通用接口）

```http
GET https://datacenter-web.eastmoney.com/api/data/v1/get
    ?reportName=RPT_F10_FINANCE_GINCOME
    &columns=ALL
    &filter=(SECURITY_CODE="600519")
    &sortColumns=REPORT_DATE&sortTypes=-1
    &pageNumber=1&pageSize=50
    &source=WEB&client=WEB
```

常用 `reportName`：

| 用途 | reportName | 关键字段 |
|---|---|---|
| 资产负债表 | `RPT_F10_FINANCE_GBALANCE` | `TOTAL_ASSETS`, `TOTAL_LIABILITIES` |
| 利润表 | `RPT_F10_FINANCE_GINCOME` | `OPERATE_INCOME`, `NETPROFIT`, `PARENT_NETPROFIT` |
| 现金流量表 | `RPT_F10_FINANCE_GCASHFLOW` | 经营/投资/筹资活动现金流净额 |
| 主要指标 | `RPT_F10_FINANCE_MAINFINADATA` | ROE、毛利率、EPS、资产负债率 |
| 全市场业绩报表 | `RPT_LICO_FN_CPD` | 营收、净利（截面批量） |
| 业绩预告 | `RPT_PUBLIC_OP_NEWPREDICT` | 预告上下限 |

- 返回为"逐期一行、扁平字段"，单只最多约 40 期；`pageSize` 20~50。
- **口径**：`NETPROFIT`（净利润）≠ `PARENT_NETPROFIT`（归母净利润）。估值与龙头评分统一用**归母净利润**；同比/环比、累计/单季必须落库时区分。
- 跨源使用前对齐同一报告期、同一币种；重组追溯调整会让"看起来一致"的数字含义不同，标记 `restated` 标志。

### 2.4 巨潮资讯 — 公告检索（一手核对层）

```http
POST http://www.cninfo.com.cn/new/hisAnnouncement/query
Content-Type: application/x-www-form-urlencoded

pageNum=1&pageSize=30&column=szse&tabName=fulltext
&stock=000001,gssz0000001
&category=category_ndbg_szsh
&seDate=2025-01-01~2026-11-25
&sortName=time&sortType=desc&isHLtitle=true
```

- `column`：`szse` / `sse` / `bjse`；全市场拆三次。
- `category`：年报 `category_ndbg_szsh`、半年报 `category_bndbg_szsh`、一季报 `category_yjdbg_szsh`、三季报 `category_sjdbg_szsh`。
- `stock` 中的 orgId **必须**通过 `POST http://www.cninfo.com.cn/new/information/topSearch/query` 按代码反查，禁止自拼（各板块形态不同，自拼易得 0 条假阴性）。
- `announcementTime` 是**毫秒时间戳**（北京时间）；PDF 直链 = `https://static.cninfo.com.cn/` + `adjunctUrl`。
- 分页终止条件：`hasMore == false` 且数组为空。
- PDF 解析是工程量最大的一环：一期只做"公告元数据 + 定期报告 PDF 下载存档"，业务构成结构化先用东财 F10，后续再做 PDF 表格抽取交叉校验。

### 2.5 政策源（C 类，需定向适配）

| 来源 | 获取方式 | 说明 |
|---|---|---|
| 国务院 / gov.cn | 政策文件栏目列表页解析 + RSS（如有） | 顶层文件，级别权重最高 |
| 发改委 / 工信部 / 财政部 / 证监会 | 政策发布栏目列表页解析 | 部委文件，落地较快 |
| 省级政府 | 重点省份定向栏目 | 地方试点，覆盖面有限、权重低 |
| 交易所 | 规则/监管问答 | 监管类，双向影响 |

**不做全网泛搜**：维护一个"政策源白名单 + 栏目 URL 清单"，只抓白名单。政策增量识别规则见 `04-核心算法设计.md` 第 3 节。

## 3. 连接器统一约定

### 3.1 每个连接器必须实现的接口

```python
class Connector(Protocol):
    source_code: str          # 'EM_F10' / 'CNINFO' / 'GOV_CN'
    def fetch(self, task: FetchTask) -> RawEnvelope: ...
    def parse(self, raw: RawEnvelope) -> list[StandardRecord]: ...
```

`RawEnvelope` 至少含：

```json
{
  "source_code": "EM_F10",
  "source_url": "https://...",
  "external_key": "SZ000001",
  "params": {"report_period": "2025-12-31"},
  "fetched_at": "2026-11-25T19:30:00+08:00",
  "http_status": 200,
  "raw_hash": "sha256:...",
  "payload": { }
}
```

### 3.2 限流、重试与熔断

| 项 | 规则 |
|---|---|
| 最小请求间隔 | 东财 ≥ 1 秒/请求，按源 IP 计；巨潮 ≥ 0.5 秒，遇 403 立即退避 |
| 并发 | 单源默认 1~2 并发；不同源可并行；全局限速器按 `source_code` 分桶 |
| 重试 | 指数退避 `1s → 2s → 4s → 8s`，最多 4 次；429/403 触发更长冷却（≥ 5 分钟） |
| 熔断 | 连续 10 次失败 → 熔断该源 30 分钟，告警；熔断期间任务标记 `degraded` 而非失败 |
| 去重 | 请求前查 `fetch_cache(external_key, params, date)`；原样命中则跳过 |
| 超时 | 连接 5s / 读取 15s / 单任务总时限 60s |

### 3.3 归一化规则（进 DWD 前必须通过）

1. **代码**：所有外部代码 → `company_id`（`SH/SZ/BJ` + 6 位），映射不存在则丢弃 + 告警。
2. **日期**：`report_period` 统一 `YYYY-MM-DD`；报告期是期末日，不是披露日；两者都存。
3. **数值**：金额统一人民币"元"；百分比统一小数（0.25 表示 25%）；空字符串 → `NULL`，不写 0。
4. **枚举**：`dimension`（行业/产品/地区）、`statement_type`（合并/母公司）、`is_adjusted` 用受控字典。
5. **来源标注**：每条标准记录自带 `source_code`、`source_url`、`source_date`、`confidence`。
6. **不可变**：原始层写入后不修改；重跑产生新 `raw_hash` 和新版本。

### 3.4 采集任务分层（避免全量高频）

| 任务 | 范围 | 频率 | 触发方式 |
|---|---|---|---|
| `sync_security_master` | 全市场证券列表 | 每周一 | 定时 |
| `sync_company_profile` | 全市场公司概况 | 每周一次（分批） | 定时 |
| `sync_quote_snapshot` | 龙头池 + 观察池 | 每交易日收盘后 | 定时 |
| `sync_financials` | 龙头池 + 候选池 | 财报季每日增量 | 定时 + 公告触发 |
| `sync_business_segment` | 龙头池 | 年报/中报披露后 | 定时 + 公告触发 |
| `sync_policy_docs` | 政策白名单栏目 | 每日 | 定时 |
| `parse_report_pdf` | 定期报告 PDF | 按需 | 半自动 |

## 4. 数据质量与容错

- **字段缺失**：连接器返回 `None`，由质量层决定是否阻塞下游；不允许连接器"猜一个值"。
- **异常值**：收入/市值为负、占比之和偏离 100% 超过阈值（默认 ±2%）→ 标 `quality_flag`，进人工复核队列。
- **接口改版**：关键字段缺失率 > 30% 时自动熔断该接口并告警，不产出该批数据。
- **抽检**：每周随机抽 5 家龙头，把 F10 主营构成与年报 PDF 表格核对，记录一致率。

## 5. 合规边界（必须遵守）

1. 上述东财/巨潮接口是网页背后公开接口，并非官方授权的个人/商业 API。本项目按**个人研究、低频访问**设计；如商业化对外提供服务，必须改为 Choice/iFinD/Wind 等授权数据源或取得网站授权。
2. 严格遵守目标网站 robots 与服务条款，不绕过登录/验证码，不进行高频并发抓取。
3. 原始公告 PDF 仅作内部研究存档，不对外分发。
4. 政策原文引用注明发文机关、文号、发布日期；媒体解读标注"非一手来源，需核实原文"。
5. 不采集个人敏感信息；用户自选股/关注列表本地或内网存储。
