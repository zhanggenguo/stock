# 06 — 合规与风险设计

## 1. 数据合规

| 风险 | 设计约束 |
|---|---|
| 非官方接口 | 东财/巨潮接口为网页背后公开接口，非授权 API。按**个人研究、低频访问**设计；不绕过登录/验证码，不做高频并发 |
| 商业化 | 若对外提供数据服务或商业化，须切换 Choice/iFinD/Wind 等授权源，或取得网站书面授权 |
| 版权 | 公告 PDF 仅内部存档，不对外分发；引用政策/研报注明出处，研报标注"非一手来源，需核实原文" |
| 个人信息 | 不采集董监高个人联系方式等敏感信息；用户关注列表内网存储，不上传第三方 |
|  robots/条款 | 遵守目标站点 robots.txt 与服务条款；建立白名单 URL 清单，不扫描无关路径 |

## 2. 数据口径风险（最易出事的地方）

| 风险点 | 防范措施 |
|---|---|
| 代码串标的 | 强制 `company_id` 映射校验；secid 市场号错误直接拒绝入库 |
| 净利润 vs 归母净利润 | 表字段分列，评分/估值只用归母；前端显示字段中文全称 |
| 同比 vs 环比 / 累计 vs 单季 | `period_type` 与 `is_cumulative` 显式存储；单季倒推值标 `derived` |
| 财年 vs 自然年 | A 股为自然年；扩展港美股时按自然年季度对齐或用 TTM 比较 |
| 东财行业 vs 申万行业 | 多口径并存，比较前先核对 `scheme` |
| 追溯调整 | `is_restated=true` 的记录单独标记，重算时注明口径变化 |
| 市值口径 | 总股本 vs 流通股本分列；估值用总市值，偏差校验 |
| 政策热度污染基本面 | 政策分与质量分分路计算，最终才合成 |

## 3. 模型风险

| 风险 | 防范 |
|---|---|
| 幸存者偏差 | 退市/ST 公司保留主体与历史数据；回测时不得剔除 |
| 过度拟合 | 权重从简（少量参数），用样本外时段验证；调整权重需新版本 + 对比 |
| 龙头名单僵化 | 每期强制与上期对比，变化必须有可解释原因 |
| 数据缺失被当成 0 | 缺失写 NULL；评分缺维度时权重分摊并降级 confidence |
| 政策误读 | 增量识别规则 + 人工复核；只认官方正式文件，不把新闻当政策 |
| 观点同质化 | 展示 `counter_signals`（反证信号）；不给目标价与仓位 |
| LLM 幻觉（如引入） | LLM 只做文本分类辅助，输出必须附原文摘录与来源链接；不参与数值计算 |

## 4. 输出与展示合规

- 每个投资观点页面**同时**展示：数据时点、来源、关键假设、反证信号、置信度、免责声明。
- 禁止用语：目标价、买入/卖出/持有指令、建议仓位、"稳赚/必涨"等确定性表述。
- 允许用语：显著低估/低估/合理/偏高/高估（研究标签）、"需进一步核实"、"数据未覆盖"。
- 观点必须经人工复核 `published=true` 才对外展示；未复核内容仅内部可见并标"草稿"。
- 评级是概率性、条件性判断，反证信号触发时自动降级为"观察"。

**固定免责声明（所有展示投资观点的页面必须包含）**：
